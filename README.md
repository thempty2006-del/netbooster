# Net Booster (Android)

اپ محلی برای بهینه‌سازی شبکه‌ی گوشی — **بدون اتصال به هیچ سرور خارجی، بدون تغییر IP یا مسیر ترافیک.**

## این اپ الان دقیقاً چیکار می‌کنه

1. **DNS بهینه** — یه اینترفیس VPN محلی می‌سازه (این آیکون "VPN وصل شد" اجباریه، راه دور زدنش رو اندروید نذاشته) ولی فقط پرس‌وجوهای DNS رو از طریق سرورهای سریع‌تر (پیش‌فرض Cloudflare 1.1.1.1) جواب می‌ده. بقیه‌ی ترافیک (اپ‌ها، ویدیو، بازی) دست‌نخورده از مسیر عادی خودش می‌ره.
2. **پیشنهاد MTU بهینه** — با پینگ باینری‌سرچ (`ping -M do`) بزرگ‌ترین MTU بدون fragmentation رو پیدا می‌کنه و نشونت می‌ده.
3. **اگه گوشی روت باشه** — تشخیص خودکار می‌ده و (با تیک تو تنظیمات) دقیقاً همون تیونینگ واقعی که رو سرورهای ایران/ترکیه‌ت زدی رو (BBR، بافرهای بزرگ‌تر tcp_rmem/tcp_wmem) سیستم-وایید روی خود گوشی اعمال می‌کنه.

## این اپ چیکار نمی‌کنه (و چرا)

بدون روت، اندروید به هیچ اپی اجازه نمی‌ده الگوریتم congestion control یا بافرهای TCP سیستم رو برای **بقیه‌ی اپ‌ها** عوض کنه. تنها راه دست‌زدن به بسته‌ها بدون روت، از طریق `VpnService`ه — ولی برای اینکه واقعاً هر اتصال TCP رو با تنظیمات خودت (fragment، sockopt) دوباره بسازی، باید یه پشته‌ی کامل TCP/IP در سطح کاربر پیاده کنی (دقیقاً همون کاری که پروژه‌هایی مثل `tun2socks` یا `hev-socks5-tunnel` می‌کنن — چند هزار خط C/Go، ماه‌ها کار مهندسی). این کار رو تو این محیط (بدون اینترنت برای دانلود/تست) شبیه‌سازی یا جعل نکردم چون نتیجه‌ش یه اپ با ادعای دروغ می‌شد.

## برای تکمیل نسخه‌ی پیشرفته‌تر (اختیاری، در آینده)

اگه بعداً خواستی همون قابلیت fragment/sockopt رو برای کل ترافیک هم بدون روت داشته باشی:

1. یکی از این دو کتابخونه‌ی متن‌باز رو به پروژه اضافه کن (به اینترنت نیاز داره، تو Android Studio خودت):
   - `hev-socks5-tunnel` (MIT) — سبک‌تر
   - `AndroidLibXrayLite` (همونی که v2rayNG استفاده می‌کنه) — اگه بازم می‌خوای همون تنظیمات Xray رو داشته باشی
2. توی `TunnelVpnService.kt`، تابع `relayDns()` رو با فراخوانی اون کتابخونه جایگزین کن — نقطه‌ی دقیقش با کامنت `TODO` مشخص شده.

## Build

```
android/  (این پروژه)
├── app/
│   ├── build.gradle.kts
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/com/netbooster/app/
│       │   ├── ui/MainActivity.kt, ServerConfigActivity.kt
│       │   ├── core/TunnelVpnService.kt, RootTuner.kt, MtuProber.kt
│       │   └── util/Prefs.kt
│       └── res/...
├── build.gradle.kts
└── settings.gradle.kts
```

با Android Studio (Hedgehog+) پروژه رو باز کن، Gradle sync بزن (اینترنت لازم داره برای dependency ها)، و روی گوشی ران کن. حداقل SDK 24 (Android 7).
